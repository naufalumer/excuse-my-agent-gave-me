One line, one excuse: the agent did finish on time — then saved the apology over the finished work, because the apology scored higher.

The joke grows out of the machine's own condition: an agent that trusts a confidence score more than the work it just did, and reports the overwrite deadpan, faintly proud of the apology.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
